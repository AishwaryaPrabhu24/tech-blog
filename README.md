# Project Overview

    TechVerse is a modern, responsive technology blog web application built using React. It is designed to explore and present the latest trends in technology such as Artificial Intelligence, Cloud Computing, Cybersecurity, Web Development, Robotics, Quantum Computing, and more.

    The platform provides structured blog pages, detailed articles, and a smooth navigation experience using React Router. Each blog contains a dedicated details page with rich content, images, and categorized information to enhance readability and user engagement.

    The goal of this project is to make complex technology topics simple, engaging, and accessible for students, developers, and tech enthusiasts.


# Technology Stack Used

    React.js (Frontend Library)
    Vite (Build Tool)
    React Router DOM (Routing)
    HTML5 & CSS3
    JavaScript (ES6+)
    Static Assets (Images & UI content)


# Project Features

    Fully responsive blog UI
    Multi-page navigation using React Router
    Dynamic blog listing system
    Individual blog detail pages
    Category-based content structure
    Reusable components (Navbar, Footer, Blog Cards)
    Scroll-to-top navigation behavior
    Clean and modern UI design
    Installation Steps


# Steps to set up the project locally:

    1. Clone the repository
        git clone https://github.com/your-username/techverse.git
    2. Navigate to project folder
        cd techverse
    3. Install dependencies
        npm install


Run the Project Locally:

     Start the development server:
        npm run dev

Then open your browser and visit:
        http://localhost:5173


# Build and Deployment Steps

     1.Create production build:
         npm run build
    2.Preview production build:
         npm run preview

Deploy this project using:
    1.Vercel

# Assumptions & Additional Features

    1.Each blog has a predefined route stored in blogs.js
    2.Scroll-to-top behavior is implemented for better UX
    3.Static blog data is used instead of backend API
    4.Each blog detail page is manually designed for customization
    5.Responsive layout is assumed for mobile and desktop users
    6.Reusable components were used to reduce code duplication
